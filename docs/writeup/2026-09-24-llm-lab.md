# LLM Lab

Every LLM call in Libiamo is now a declared recipe, and admins get an in-app workbench to inspect, re-run and compare those calls without touching learner data.

## What changed for the code

- `server/llm.ts` became `server/llm/`: `client.ts` is the old transport (plus explicit provider routes that skip trial quota), `recipe.ts` declares recipes, `run.ts` runs them.
- All 13 call sites (agent replies, hints, feedback and follow-up, translation help, Notes, translation candidates, Generation 1/2 and both verifiers) are recipes with JSON-plain input and a pure `finalize`. Domain code keeps its DB reads and writes.
- Notes, feedback annotation and agent replies expose slot templates; their defaults render the previous prompts byte for byte (checked against the old code before committing).
- Every call thinks (OpenAI-spec `reasoning_effort`, low or medium per recipe) and shares one 32,768-token output budget; the Lab can override the effort.
- Tracing and overrides plug in through one interceptor installed at boot. Without it (tests, `LLM_LAB=off`) recipes run exactly as declared.

## What admins can do

- **Guide** (`/admin/lab`): a Chinese/English explanation of every Lab concept and step-by-step use of each page.

- **Traces** (`/admin/lab/traces`): every captured real-flow call (on by default; only learners on their own API key can turn it off), with the structured input, the messages by section, the rendered output (Notes as cards, feedback as marked-up text), attempts and repair errors, model, latency and tokens. Rate it, pin it to a dataset, or delete it (one at a time or a whole filtered view; run outputs go only with their run).
- **Playground**: re-run a trace or case with edited slots, input, provider, temperature or hand-edited messages, next to the original output. Opened directly, it offers recent real calls to start from.
- **Datasets and runs**: gather cases around a question, run them across columns of variants (and repeats) in the background, score them with an LLM judge and votes, and compare per-column statistics.
- **Overrides**: use a slot/provider/temperature variant for your own real-flow calls; the inspector's LLM tab marks when one is active.
- **Inspector**: an LLM tab on every app page lists your own recent calls, narrowed to the task you are on.

## For learners

A Profile checkbox ("Help improve AI features") opts in to capture; the privacy policy describes retention (30 days, pinned examples kept and detached on account deletion). Nothing else changes for learners, and the inspector code is never downloaded by them.

## Operations

Migration `0024_llm_lab` adds eight `llm_*` tables. New environment variables: `LLM_LAB`, `LLM_LAB_PROVIDERS`, `LLM_LAB_CONCURRENCY` (see `.env.example`). The Lab worker runs in the web process next to the agent-reply worker and purges expired traces hourly.
